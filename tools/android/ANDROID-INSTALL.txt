BRIMIR FOR ANDROID
Sega Saturn core for RetroArch

In this download:
  brimir_libretro_android.so  the core
  brimir_libretro.info        optional (below)
  ANDROID-INSTALL.txt         this text
Brimir is a core, not an app. You need
RetroArch, a Saturn BIOS and your games.
None of them is included.

1. GET RETROARCH (64-bit, 1.22.2 or newer)
  - "RetroArch (AArch64)" APK:
    https://buildbot.libretro.com/stable/1.22.2/android/RetroArch_aarch64.apk
  - or the Play Store RetroArch (not tested
    with Brimir).
Install only one RetroArch package. Do not
mix the AArch64 one with "RetroArch".
If RetroArch closes right after you open it:
RetroArch 1.22.2 (the universal APK, tested
on the emulator) does not start on Android
with 16 KB memory pages. The universal
nightly build works there: RetroArch.apk
(package com.retroarch) from
https://buildbot.libretro.com/nightly/android/
Uninstall the AArch64 one before you
install it.

2. INSTALL THE CORE
Copy brimir_libretro_android.so to the
phone's Download folder. Keep the name.
In RetroArch: Main Menu > Load Core >
Install or Restore a Core. Tap "Parent
Directory" twice (you are in
/storage/emulated/0), open "Download", tap
brimir_libretro_android.so. RetroArch
copies it and returns to the Main Menu.
Then Load Core > brimir_libretro_android.so.
"Start Core" now runs the Saturn BIOS menu.

3. BIOS (needed)
Copy one into RetroArch's System folder
(Settings > Directory > System/BIOS, usually
/storage/emulated/0/RetroArch/system):
  mpr-17933.bin
  Sega Saturn BIOS v1.01 (JAP).bin
  Sega Saturn BIOS (EUR).bin
The .info file lists more names. With one
Japan and one US/EU BIOS, Brimir picks the
one that fits the disc.

4. GAMES
.chd, .cue (with its .bin files), .ccd,
.mds, .iso, .m3u in any folder RetroArch
can open, e.g. RetroArch/roms or Download.
Main Menu > Load Content > pick the game.

THE .INFO FILE (OPTIONAL)
Without it all works; the core is listed as
"brimir_libretro_android.so". With it
RetroArch says "Sega - Saturn (Brimir)" and
shows which BIOS files it found (Core
Information). To use it: copy it to a folder
(e.g. /storage/emulated/0/RetroArch/info),
then Settings > Directory > Core Info >
choose that folder.
WARNING: RetroArch then reads info files
ONLY from that folder. The info files of
your other cores are no longer found unless
you copy them there. With other cores, skip
the .info file.

RENDERER
Default: Software, works on every phone.
Optional Vulkan: RetroArch video driver =
vulkan, core option "Renderer (restart
required)" = Vulkan, and a Vulkan 1.2 GPU.
Otherwise Brimir uses Software and logs
the reason ("Device report:" line in
RetroArch's log).
With Vulkan and run-ahead "Use Second
Instance", RetroArch's message "Failed to
create second instance. Run-Ahead will now
use only one instance." is expected.
Details (test guide):
https://github.com/coredds/brimir/blob/master/tools/android/TEST-GUIDE.md

TESTED ON
  - x86_64 Android emulator (Android 14 and 15)
  - Samsung Galaxy A56: in testing, no result yet
NOT tested: Mali and Adreno phones.
