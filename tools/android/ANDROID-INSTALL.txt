BRIMIR FOR ANDROID
Sega Saturn core for RetroArch

Brimir is a core, not an app: you need
RetroArch, a Saturn BIOS and your games
(none included). Also in this download:
brimir_libretro.info (needed, step 3).

1. GET RETROARCH (64-bit, 1.22.2 or newer)
Install ONE: the libretro site APK
https://buildbot.libretro.com/stable/1.22.2/android/RetroArch.apk
or the Play Store RetroArch (folders: step 4).
Closes at start (16 KB memory pages; the A56
has 4 KB)? See the guide.

2. INSTALL THE CORE
Copy brimir_libretro_android.so to a folder
RetroArch can show. Keep the name. Then:
Main Menu > Load Core > Install or Restore a
Core, open the folder RetroArch shows (APK:
Parent Directory twice, then Download), tap
the file. Then Load Core > brimir_libretro_
android.so. "Start Core" runs the BIOS menu.

3. THE .INFO FILE AND THE FILE FILTER
Without both, RetroArch hid the games or
said no core is available for .chd. Do both:
  - Copy brimir_libretro.info to a folder,
    set Settings > Directory > Core Info to
    it, restart RetroArch.
  - Turn the file browser filter OFF:
    Settings > User Interface > File Browser
    > Filter Unknown Extensions (label from
    RetroArch's source, not checked on a
    phone; config key menu_navigation_browser_
    filter_supported_extensions_enable).
Trade-off: the Core Info folder replaces
RetroArch's own info files for every core.
An official fix (Brimir's .info in
libretro's core info files) is planned.

4. FOLDERS, BIOS AND GAMES
RetroArch's folder: APK
/storage/emulated/0/RetroArch, Play Store
/storage/emulated/0/Android/media/
com.retroarch/RetroArch
BIOS (one is enough) into its "system"
folder: mpr-17933.bin, Sega Saturn BIOS
v1.01 (JAP).bin or Sega Saturn BIOS
(EUR).bin. Games: a folder RetroArch can
browse, e.g. "roms" inside that folder.
Then Load Content > the game.

SAVES
Close Content (or Quit) before you leave
RetroArch. Swiping it away, or Android
closing it, keeps only what RetroArch's
autosave already wrote. After an in-game
save keep playing 10-15 s before you
switch apps.

RENDERER
Default: Software (poor performance on the
A56). Vulkan: Settings > Drivers > Video =
vulkan, restart RetroArch, core option
Renderer = Vulkan, then CLOSE CONTENT AND
LOAD THE GAME AGAIN (applies on load).
Needs a Vulkan 1.2 GPU, else Software. No
internal resolution above 1x on Android yet
(it froze an A56). Guide:
https://github.com/coredds/brimir/blob/master/tools/android/TEST-GUIDE.md

TESTED ON
  - Samsung Galaxy A56 (Exynos 1580,
    Xclipse 540 GPU, Android 17): BIOS menu
    and games run. Vulkan renderer: full
    speed at 1x (developer's observation) in
    the games tried. Software renderer: poor
    performance.
  - x86_64 Android emulator (Android 14, 15)
NOT tested: Mali and Adreno phones; phones
with 16 KB memory pages; app kill or
swipe-away (the saves advice comes from
RetroArch's source and Brimir's tests). The
A56's Vulkan "Device report" log line was
not read. Reports are welcome:
https://github.com/coredds/brimir
