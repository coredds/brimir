# ThreadSanitizer suppressions for the CI job test-linux-tsan.
#
# Upstream Ymir's threaded VDP renderers race with the emulation thread (VDP register and state
# structures read and written without synchronization, e.g. VDP2State::UpdateEnabledBGs against
# SoftwareVDPRenderer::VDP2RenderThread, found with TSan in milestone 2E). They are not part of
# the JIT and the vendored core is not ours to fix here. Every test that initializes a CoreWrapper
# starts those threads, so without these the run is dominated by them.
#
# A suppression matches a report when any frame of either stack matches. So a race with one side in
# ymir::vdp:: is not checked even when the other side is JIT code (for example a generated block
# or a trampoline writing a VDP register through the bus). That is a gap in this job, and it is
# accepted: those accesses go through the core's bus, not through the JIT's own state.
#
# The JIT's own threading (CompileWorker, PreparedCompile::Finalize, BlockCache) is covered: a race
# between the worker and the emulation thread has no VDP frame in either stack, so it is reported.
race:ymir::vdp::
race:moodycamel::
